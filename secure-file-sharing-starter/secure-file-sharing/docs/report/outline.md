# Khung báo cáo đề xuất

1. Giới thiệu: bài toán, mục tiêu, phạm vi, phân công.
2. Cơ sở lý thuyết: E2EE, AES-GCM, RSA-OAEP, SHA-256, quản lý khóa.
3. Phân tích và thiết kế: use case, kiến trúc, ERD, API, threat model.
4. Cài đặt: frontend, backend, database, luồng tệp và khóa.
5. Kiểm thử và thực nghiệm: test âm, phân quyền, kết quả đo, giới hạn.
6. Kết luận và hướng phát triển: ECC, backup khóa mã hóa, nhiều thiết bị, tệp lớn.

Điều chỉnh theo mẫu của giảng viên; mỗi thành viên viết phần mình phụ trách.
